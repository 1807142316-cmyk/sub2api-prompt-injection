# 账号 Codex 请求兼容

入口为“账号管理”中的新增或编辑账号，仅 OpenAI API Key 类型显示。

- “Codex 请求兼容”开关为当前账号设置 User-Agent；填写实际客户端使用的完整值。
- 关闭后保留填写值，方便再次启用。关闭不会删除账号已有自定义请求头、安装标识，也不更改提示词或透传模式。
- 已启用的自定义请求头中，非空 `User-Agent` 优先于此处。高级请求头模板仍按上游原有的认证上下文规则解析。
- 未操作的旧账号保持原配置。已经通过自定义请求头接通的账号不需要重新启用此开关。
- Responses 透传、接口模式和模型准入继续独立设置。兼容开关不会更改请求正文、模型名、工具参数、额度或分组。

存储字段为账号 `credentials.codex_request_compat_enabled` 和
`credentials.codex_request_compat_user_agent`。没有新增数据库迁移。
后端在现有请求头应用入口执行，因此已保存账号的模型列表、账号测试和实际请求使用一致配置。
批量更新先逐个校验各账号合并后的最终配置：仅开启时沿用各自保存的 User-Agent，已启用时不能只清空 User-Agent。修改兼容开关或 User-Agent 会使相关计费探测缓存失效。
创建页未保存账号的模型预览沿用上游接口，目前不接收这些账号级配置；先保存账号后同步模型。
该选项不会生成静态会话、轮次、窗口或安装 ID，不保证上游永久接受所有客户端或参数组合。

AgentRouter 既有账号使用原自定义 User-Agent 并保留精确模型名；
此前验证结果和上游工具流限制见 `agentrouter-integration.md`。
新选项不修改这些账号的现有设置。
